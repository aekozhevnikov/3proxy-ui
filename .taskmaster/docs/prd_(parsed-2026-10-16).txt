# Docker Image Size Optimization

## Objective
Reduce 3proxy-ui Docker image from 1.3GB to at most 900MB while maintaining functionality.

## Current Analysis
- Base: node:20.18-alpine
- Runtime packages: curl, docker-cli, fail2ban, iptables, python3, sqlite-libs
- node_modules 1GB with devDependencies still present in runtime stage
- Multi-stage build already in place

## Tasks

### Task 1: Analyze Docker image size breakdown
Run docker history or dive to identify largest layers. Document findings.

### Task 2: Remove devDependencies from runtime stage
Modify Dockerfile to install only production dependencies in runtime stage using npm ci --omit=dev.

### Task 3: Remove unnecessary runtime packages
Evaluate and remove docker-cli if not needed. Only keep essential packages.

### Task 4: Optimize node_modules in build stage
Remove types, tests, docs after install. Prune aggressively.

### Task 5: Build and verify optimized image
Build image, check size <=900MB. Verify app starts and features work.

### Task 6: Run tests for verification
Run test suite to ensure no regressions.
