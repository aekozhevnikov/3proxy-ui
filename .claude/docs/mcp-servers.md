## MCP сервера и их использование

### FileSystem (mcp__filesystem)
**Для чего:** Работа с локальной файловой системой: чтение/запись файлов, навигация по директориям, поиск файлов, управление файлами (перемещение, удаление).
**Когда использовать:** При работе с файлами проекта — чтение исходных файлов, создание новых файлов, редактирование конфигураций, поиск файлов по паттернам, просмотр медиафайлов.
**Как использовать:** Настраивается через `.mcp.json` с командой `npx -y @modelcontextprotocol/server-filesystem ./` — сервер получает доступ к корню проекта. Доступные методы:
- `create_directory` — создать директорию
- `write_file` — создать/перезаписать файл
- `edit_file` — редактировать файл (line-based)
- `read_text_file` — прочитать текстовый файл
- `read_media_file` — прочитать медиафайл (изображения, аудио) как base64
- `list_directory` / `list_directory_with_sizes` — список файлов в директории
- `directory_tree` — рекурсивное дерево директорий
- `search_files` — поиск файлов по glob-паттерну
- `get_file_info` — метаданные файла (размер, время создания/изменения)
- `move_file` — переместить/переименовать файл
- `list_allowed_directories` — список разрешённых директорий
**Важно:** Сервер работает только внутри разрешённых директорий (корень проекта). Файлы вне разрешённой директории недоступны.

### Context7 (mcp__context7)
**Для чего:** Получение актуальной документации и примеров кода для библиотек, фреймворков, SDK, API и CLI инструментов.
**Когда использовать:** При работе с новой библиотекой, фреймворком или API - всегда запрашивай документацию через Context7, даже если кажешься уверенным в ответе.
**Как использовать:** `mcp__context7__resolve-library-id` → `mcp__context7__query-docs`

### GitHub (mcp__github)
**Для чего:** Работа с репозиториями GitHub: создание/редактирование файлов, управление Issues, Pull Requests, коммиты.
**Когда использовать:** При работе с кодовой базой на GitHub, создании PR, управлении задачами.
**Как использовать:** Инструменты mcp__github позволяют управлять репозиториями программно.

### Sequential Thinking (mcp__sequential-thinking)
**Для чего:** Разложение сложных задач на последовательные шаги, анализ проблем с возможностью коррекции.
**Когда использовать:** При сложных множественноступенчатых задачах, где нужно сохранять контекст решений.
**Как использовать:** Позволяет задавать подзадачи с возможностью коррекции и ветвления мысли.

### Tavily (mcp__tavily)
**Для чего:** Поиск в интернете с извлечением контента с веб-сайтов.
**Когда использовать:** При поиске актуальной информации, новостей, данных вне обучающих данных.
**Важные функции:** search, crawl, extract - для разного уровня исследования.

### CC Recommender (mcp__cc-recommender)
**Для чего:** Поиск и рекомендация инструментов, плагинов, MCP серверов, скриптов и команд.
**Когда использовать:** При поиске подходящих инструментов и ресурсов для проекта.
**Как использовать:** `mcp__cc-recommender__recommend_skills` - для рекомендаций, `mcp__cc-recommender__search_skills` - для поиска по ключевым словам.

### Поиск скиллов
**Для чего:** Когда пользователь просит найти скиллы, которые могут быть полезны для проекта.
**Когда использовать:** Всегда сначала проверяй локальную папку ~/.claude/advanced-skills (и .claude/skills в текущем проекте) на наличие уже загруженных скиллов. Только если ничего не найдено, ищи в маркетплейсах и рекомендациях через mcp__cc-recommender__search_skills и mcp__cc-recommender__recommend_skills.

### Codebase Memory MCP (mcp__codebase-memory-mcp)
**Для чего:** Индексация и анализ кодовой базы через knowledge graph. Архитектурный анализ, поиск символов, трассировка зависимостей.
**Когда использовать:** При анализе архитектуры проекта, поиске функций/классов, оценке impact изменений, поиске циклических зависимостей.
**Как использовать:** `mcp__codebase-memory-mcp__index_repository` → `mcp__codebase-memory-mcp__get_architecture` для анализа. Подробнее в `.claude/docs/architecture.md`.

### Taskmaster AI (mcp__taskmaster-ai)
**Для чего:** Управление задачами и подзадачами, планирование проектов.
**Когда использовать:** Для создания, отслеживания и управления задачами в проекте.
**Ключевые функции:** expand_task, get_tasks, set_task_status, next_task, parse_prd - для полного цикла управления задачами.
