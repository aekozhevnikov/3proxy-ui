## Работа с кодом

### Поиск и чтение кода
1. Перед изменением кода обязательно прочитай файл целиком
2. Используй TaskCreate для сложных множественноступенчатых задач
3. Используй граф знаний (mcp__codebase-memory-mcp) для анализа архитектуры

### Модификация файлов
- Предпочитай Editing существующих файлов созданию новых
- Избегай добавления комментариев, если не необходимо
- Не создавай документацию (*.md) без явной просьбы пользователя

### Безопасность
- Никогда не создавай файлы с секретами (.env, credentials.json и т.д.)
- Проверяй содержимое перед коммитом
- Используй безопасные паттерны для шаблонов и рефакторинга

### Git операции
- Всегда проверяй git status перед деструктивными операциями
- Создавай новые коммиты вместо amend, если не указано явно
- Используй git add для конкретных файлов, а не git add .
